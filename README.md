# Job Schedule and Earnings

An offline-first progressive web app (PWA) for tracking tuition schedules, cancellations and job hours.

## Features

- Works offline via a service worker (`sw.js`)
- Installable on a phone home screen (`manifest.json`)
- Tracks lessons, cancellations and hours worked

## Usage

No build step. Open `index.html` in a browser or serve the folder with any static file server, then use "Add to Home Screen" to install it.
